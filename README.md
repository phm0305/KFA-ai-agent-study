# KFA-ai-agent-study
KFA 2학기 AI 에이전트 스터디: 데이터로 기업에 대한 자기 판단 세워보기

> 처음 오셨다면 [docs/SETUP.md](docs/SETUP.md)부터 보세요.

## 목적
- **목적:** 데이터로 기업에 대한 자기 판단을 세워보는 것. 결과가 맞고 틀리고보다, 어떤 데이터로 어떤 논리를 세웠는지가 산출물 (`data → information`)
- **수단:** 그 과정을 반복할 수 있게 AI 에이전트로 수집·정리를 자동화. 자동화는 판단을 여러 번 연습하기 위한 도구지 그 자체가 목표가 아님
- **신뢰성 원칙:** 에이전트가 가져온 재료를 그대로 믿지 않고, 무엇이 틀렸고 무엇이 빠졌는지 사람이 확인하며 도구를 고쳐나감

> 리서치에 필요한 데이터를 찾아내고, AI 비서가 그걸 모으고 정리하게 만든 뒤, 그 재료로 자기 판단을 세운다.

## 에이전트 구조
모든 조가 같은 엔진을 쓰고, 그 위에 조마다(또는 사람마다) 산출물을 붙여요.

| 엔진 칸 | 하는 일 | 회차 |
|---|---|---|
| 1. 수집 | 어떤 소스든 같은 공통 표(숫자 하나 = 한 줄)로 받아오기 | 2회차 (완료) |
| 2. 공통 표·출처 목록 | 줄마다 번호, 출처마다 [S1] 같은 번호 붙이기 | 3회차~ |
| 3. 지표 계산 | 성장률·이익률 같은 숫자를 계산식과 함께 남기기 | 3회차~ |
| 4. 주장·숫자 대조 | 글에 적은 숫자가 원본과 맞는지 확인하기 | 4회차~ |

데이터 소스는 코드로 얼마나 자동으로 가져올 수 있는지에 따라 수집 방법 1~5단계(공식 API, 파이썬 라이브러리, 파일 다운로드, 크롤링, 수동 입력)로 나눠요. 공시·주가, 산업 데이터, 뉴스는 모두 이 단계 중 하나로 들어와요.

## 최종 산출물
엔진이 모은 재료로 만든 조별 산출물. 형식은 조마다 정하고, 해석과 판단은 각자 직접 써요.

## 폴더 구조
| 폴더 | 내용 |
|---|---|
| `setup/` | 처음 한 번 실행하는 환경점검 노트북. **여기부터 시작** |
| `docs/` | 스터디 가이드 |
| `docs/sessions/` | 회차별 자료 |
| `docs/plans/` | 스터디장 작업 계획 (조원은 안 봐도 돼요) |
| `notebooks/` | 실습 템플릿 (사본을 만들어서 작업) |
| `tools/` | 제공 도구 코드 (수집 공통 도구 등) |
| `backup/` | AI가 안 될 때 쓰는 미리 뽑아둔 결과 |
