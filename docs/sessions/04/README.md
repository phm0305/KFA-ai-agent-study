## 2. 기본값으로 끝까지

기본 글은 다섯 문장이에요. 그중 **52%는 일부러 틀린 숫자**예요.

> SK하이닉스의 2025년 매출은 97.1조 원으로 전년보다 46.8% 늘었다. 영업이익률은 52%를 기록했고, 전년 대비 13.1%포인트 높아졌다. 부채비율은 46% 수준이다. 부채비율은 전년보다 16.2%p 낮아졌다. HBM 수요가 실적을 이끌었다.

셀마다 하는 일은 이래요.

| 노트북 셀 | 하는 일 |
|---|---|
| 1. DART에서 두 해 받기 | 3회차와 같아요. 연결 재무제표 6개 계정 × 2년 = 12줄 |
| 1-1. 내 소스 붙이기 (선택) | 공통 필수에서는 비워 둬요. `⏭ 내 소스 없음: 공통 표는 DART만으로 계속해요`가 나오면 정상 |
| 2. rid와 [S#] | Gemini가 근거로 고를 줄 목록이에요 |
| 3. 지표 [M#] | 매출 성장률·영업이익률·부채비율을 위 줄들로만 계산해요 |
| 4. Gemini에 보내 저장 | 질문(규칙 + 두 표 + 글)을 보내고 답을 받은 그대로 파일에 저장해요 |
| 5. 저장한 답 읽기 | 답 원문을 먼저 보여주고, 주장 목록으로 읽어요 |
| 6. 숫자 대조 | 숫자마다 PASS / FIX / REVIEW |
| 7. 결과 파일 미리보기 | 주장 목록·지표 표·대조 표·출처 목록을 한 화면에 |

스터디장 컴퓨터에서 기본값으로 돌린 결과예요. 지표는 M1 매출 성장률 46.76%, M2 영업이익률 48.59%, M3 부채비율 45.95%이고, 숫자 대조 표는 이렇게 나와요.

| 주장 | 적은 숫자 | 실제 값 | 판정 |
|---|---|---|---|
| C-1 SK하이닉스의 2025년 매출은 97.1조 원으로 … | 97.1 조 원 | 97.147 조 원 | PASS |
| C-1 (같은 문장) | 46.8 % | 46.763 % | PASS |

## 3. 결과 읽는 법

| 판정 | 뜻 | 할 일 |
|---|---|---|
| **PASS** | 글의 숫자가 원본과 맞아요 | 없음 |
| **FIX** | 글의 숫자가 원본과 달라요. 실제 값이 같은 단위로 옆에 나와요 | 글을 고치기 |
| **REVIEW** | 코드가 혼자 판정할 수 없어서 사람에게 넘겼어요. 이유가 같이 나와요 | 이유를 읽고 사람이 판단 |

**"맞다"의 기준**은 글에 적은 숫자의 마지막 자릿수예요. 46.8%라고 적었으면 46.75 ~ 46.85% 안이면 PASS예요(±0.05%p). 52%처럼 정수로 적었으면 ±0.5%p까지 봐줘요.

**52%가 FIX인 이유**: Gemini는 "영업이익률 52%"의 근거로 지표 M2(영업이익률)를 골랐어요. M2는 DART 2025년 영업이익 ÷ 매출액 = **48.59%** 예요. 52%는 허용 범위(51.5 ~ 52.5%) 밖이라서 FIX이고, 실제 값 48.59%가 옆에 나와요.

**"근거 id가 비어 있음"과 "근거 없음"은 달라요.**

| 이유 | 뜻 | 기본 글의 예 |
|---|---|---|
| 근거 id가 비어 있음 (표에 뒷받침하는 줄이 없음) | 문장에 **숫자는 있는데**, 그 숫자가 가리키는 줄이 표에 없어요 | 13.1%포인트, 16.2%p. "전년 대비 몇 포인트"라는 **변화량**은 지금 표에 없어요(지표는 수준값만 있음) |
| 근거 없음 | 문장에 **숫자가 없어요**. 숫자로 대조할 게 없는 주장이에요 | "HBM 수요가 실적을 이끌었다" |

변화량을 수준 지표(예: 영업이익률 48.59%)에 억지로 대면 틀린 판정이 나와서, 표에 변화량 자체가 없으면 비워 두게 했어요.

## 6. 조 계획에 따라 할 것

아래 두 가지는 조 계획에 따라 해요. **(A) 방식 조는 검증을 맡은 사람 한 명이 대표로 해도 돼요.**

### 6-1. 내 소스에 검증기 붙이기

노트북 **1-1. 내 소스 붙이기 (선택)** 셀을 채워요.

1. `raise SkipStep(...)` 줄을 지우고 그 자리에 3회차에 성공한 `my_records(code)` 안쪽 코드를 붙여 넣어요
2. `MY_LEVEL`에 수집 방법 단계(1~5), `MY_TARGETS`에 종목코드를 적어요 (예: `["000660"]`)
3. 설정 셀의 `TEXT`를 **내 소스 숫자가 들어간 글**로 바꿔요
4. **런타임 → 모두 실행**

`✅ 내 소스 N줄을 공통 표에 붙였어요`가 나오면 내 소스 줄도 rid를 받아서 Gemini가 근거로 고를 수 있어요. 지표 3개는 DART 줄만 쓰니까 그대로예요.

- 글이 바뀌었으니 🗂 미리 받아 둔 답은 안 쓰여요. Gemini 키가 꼭 있어야 해요.
- 단위는 글과 내 소스 줄이 **글자 그대로 같으면**(공백 무시) 어떤 단위든 비교해요(`원/달러`, `지수`, `배` 등). 돈 단위는 `원·천원·백만원·억원·십억원·조원`끼리 바꿔서 비교해요. `%포인트`와 `%p`처럼 글자가 다르면 REVIEW예요.

### 6-2. 함정 사례 1~2개 (정답 포함)

검증기를 일부러 헷갈리게 할 만한 문장을 `TEXT`에 넣고, **돌리기 전에 정답을 먼저 적은 뒤** 결과와 비교해요. 노트북 맨 아래 텍스트 셀에 이 모양으로 적어요.

```
## 함정 사례: (한 줄 제목)
- 넣은 글: (TEXT에 넣은 문장)
- 정답: 이 숫자는 원본과 비교하면 (PASS / FIX / REVIEW)여야 한다. 이유:
- 검증기 결과: (실제로 나온 판정과 이유)
- 같았나: 같음 / 다름 (다르면 어디가)
```

검증기가 정답과 다르게 판정한 사례가 제일 값진 결과예요. 같은 내용을 조에서 정한 공유 공간에도 올려요.

## 7. 지표가 확인 필요로 나오는 경우

지표 3개는 **12월 결산 · 연결 재무제표 · 연간(사업보고서)** 숫자를 기준으로 만들었어요. 다른 회사를 넣으면 이렇게 나와요.

| 경우 | 나오는 모양 | 읽는 법 |
|---|---|---|
| 증권사·은행 같은 금융사 | 매출 성장률·영업이익률이 **확인 필요**. 부채비율은 **계산돼요** | 금융사 공시에는 일반 기업의 매출액·영업이익 계정이 없어요. 이유 칸에는 "연결 줄 없음"이 나오는데, 진짜 원인은 **위 1번 DART 표의 비고**("표준 계정을 못 찾음")를 보세요. 부채비율은 예금이 부채로 잡혀서 아주 크게 나와요(KB금융 2025: 1,211.73%). 일반 기업과 비교하면 안 돼요 |
| 12월 결산이 아닌 회사 | 확인 필요가 **안 나와요** | 아직 지원하지 않아요. 기준일이 12월 31일로 틀리게 찍힌 채 지표가 계산돼요([함정 T10](../../traps.md)). 3월·6월 결산 회사는 피해 주세요 |
| 연결 재무제표 없이 별도만 내는 회사 | **미확인**. 코드상으로는 1번 DART 셀에서 ❌ `DART 013: 조회된 데이터가 없어요`가 나고 아래 셀이 ⏭로 넘어갈 것으로 예상해요 | 이런 회사를 만나면 결과를 조 톡방에 공유해 주세요 |
| 분기 숫자 | 04 노트북은 사업보고서(연간)만 받아요. 내 소스로 분기 숫자를 넣어도 지표에는 안 쓰여요 | 분기 지표는 아직 없어요 |

확인 필요는 실패가 아니에요. 코드가 추측해서 채우지 않고 사람에게 넘긴 거예요.

## 8. 함정 안내

**최신 분기 숫자**: 3분기 보고서는 **11월 중순 무렵**에 나와요. 그래서 3분기 숫자는 그전까지 DART API에 없어요. 11월 9일에 SK하이닉스·삼성전자의 2026년 3분기를 조회했더니 둘 다 `DART 013: 조회된 데이터가 없어요`였어요. 그 전에 최신 분기 숫자가 필요하면 회사가 먼저 내는 **잠정실적 공시**(영업(잠정)실적)를 써요.

**AI가 값을 먼저 판단하는 함정 ([T12](../../traps.md))**: 처음에 Gemini에게 "숫자를 뒷받침하는 줄이 없으면 근거를 비워"라고 했더니, Gemini가 52%를 보고 "M2(48.59%)와 안 맞으니 뒷받침하는 줄이 없다"며 근거를 비웠어요. 그러면 틀린 숫자가 FIX가 아니라 REVIEW로 빠져서 오류가 숨어요. 그래서 지금은 "숫자가 가리키는 항목을 고르기만 하고, 맞는지는 판단하지 마"라고 시켜요. **맞다 틀리다는 코드만 정해요.** 내 소스로 함정 사례를 만들 때도 이런 일이 생기는지 봐 주세요.

**기간 변화율**: 주간·3개월 주가 수익률 같은 기간 변화율 지표는 아직 없어요. 상한가 같은 하루 급변이 결과를 좌우하는 문제([T2](../../traps.md))와 장 마감 전 종가 문제([T4](../../traps.md))의 규칙을 정한 뒤 추가할 예정이에요.
