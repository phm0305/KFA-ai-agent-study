## 3. 모두 실행하고 결과 읽기

**런타임 → 모두 실행**. 2~3분 걸려요. 중간에 무언가 실패해도 멈추지 않고 맨 아래까지 가요.

### 정상 결과

맨 아래 요약표가 이렇게 나오면 정상이에요. 숫자는 날짜에 따라 조금 달라질 수 있어요.

| 단계 | 예시 | 결과 | 줄 수 | 확인 필요 | 이렇게 나오는 이유 |
|---|---|---|---|---|---|
| 1 공식 API | DART 재무제표 | ✅ | 9 | 0 | 6개 계정. 손익 3개는 3개월·누적 두 줄씩 |
| 1 공식 API | ECOS 기준금리 | ⏭ | 0 | 0 | ECOS 키가 없으면 건너뜀. 키가 있으면 ✅ 9줄 전부 확인 필요(ECOS는 발표일을 안 줘서) |
| 2 파이썬 라이브러리 | 주가 | ✅ | 10 | 0 | 최근 5거래일 × 종가·거래량 |
| 3 파일 다운로드 | FRED 미국 금리 | ✅ | 5 | 0~1 | 미국 휴일이면 값이 비어 확인 필요 1줄 |
| 4 크롤링 | 한국은행 기준금리 페이지 | ✅ 또는 ⏭ | 5 | 5 | 크롤링 값은 전부 사람이 봐야 해요. 사이트가 막아 두면 ⏭ |
| 5 수동 입력 | 손으로 옮긴 숫자 예시 | ✅ | 3 | 2 | 일부러 문제 있는 숫자 2개를 넣은 연습용 예시 |
| 5 수동 입력 | 내 드라이브 출처카드 | ⏭ | 0 | 0 | `USE_DRIVE = False`면 건너뜀 |
| 1 공식 API | 내 소스 | ⏭ | 0 | 0 | 아직 안 채웠으면 건너뜀 |

그 위에는 이런 줄이 보여요.

```
✅ 칸 모양 OK: 32줄 (형식 통과 25 · 확인 필요 7)
   ⚠ 크롤링 값: 원문 화면과 한 번 대조: 5줄
   ⚠ 손으로 옮긴 값: 원문과 대조: 2줄
   ⚠ 공시일 비어 있음: 1줄
   ⚠ 숫자로 못 바꿈: '…': 1줄
   ⚠ 공시일이 기준일보다 빠름: 1줄
💾 저장: w02_records.csv w02_records_확인필요.csv
```

크롤링 예시가 ⏭면 27줄, FRED에 휴일이 끼면 확인 필요가 1줄 늘어요. 아래 세 줄(공시일 비어 있음, 숫자로 못 바꿈, 공시일이 더 빠름)은 수동 입력 예시에 일부러 넣은 문제라 매번 나와요.

### 기호 읽는 법

| 기호 | 뜻 | 할 일 |
|---|---|---|
| ✅ | 공통 표로 받아옴 | 없음 |
| ⏭ | 준비가 안 돼서 건너뜀 (키 없음, 설정 꺼짐, 사이트가 막음) | 메모 칸 읽기. 고칠 필요 없는 경우가 대부분 |
| ❌ | 실패 | 아래 "막혔을 때" 표 보기 |
| 형식 통과 | 모양이 맞다 (숫자가 **맞다**는 뜻은 아님) | 없음. 진짜 맞는지는 4회차 검증기가 봐요 |
| 확인 필요 | 코드가 혼자 판단 못 해서 사람에게 넘김 | 비고의 ⚠ 이유 읽기 |

> 예시가 ❌여도 **내 소스가 ✅면 과제는 성공**이에요. 예시는 구경용이에요.

## 4. 내 소스 붙이기 (과제 본체)

노트북 아래쪽 **✍️ 과제: 내 소스 붙이기** 셀을 채워요.

1. 첫 줄 `raise SkipStep(...)`을 지워요.
2. 내 소스에서 표를 받아오는 줄을 써요. 단계별 방법은 노트북 표에 있어요. 모르겠으면 노트북 맨 아래 **AI에게 보낼 부탁 문장 ①** 을 써요.
3. `print(table.head())`로 칸 이름을 확인해요.
4. `items`에 `{"원래 칸 이름": ("항목 이름", "단위")}`, `date_col`에 날짜 칸 이름을 적어요.
5. 꼬리표를 채워요.

   | 칸 | 무엇을 | 예 |
   |---|---|---|
   | `level` | 수집 방법 단계 | `1` |
   | `source` | 출처 이름 | `"공공데이터포털 전력거래소 SMP API"` |
   | `source_url` | 원문을 다시 찾아갈 주소 (사이트 첫 화면 말고 **데이터가 있는 페이지**) | |
   | `reliability` | 상 / 중 / 하 | `"상"` |
   | `basis` | 연결 / 별도 / `NOT_APPLICABLE` | 거시 지표면 `NOT_APPLICABLE` |
   | `disclosed` | 공시일. 그날 공개되는 숫자면 `SAME_AS_DATE`, 모르면 빼기 (확인 필요로 가요) | |

6. 셀을 실행해서 `✅ 내 소스: N줄`이 나오면 성공이에요.
7. 맨 아래 **📋 다 합치고 저장하기** 셀을 다시 실행해요. 내 소스가 합쳐진 CSV가 저장돼요.

### 성공 기준

- [ ] 요약표의 `내 소스`가 ✅
- [ ] `check_records`가 `✅ 칸 모양 OK`
- [ ] 확인 필요가 있다면 이유를 이해했고, 고칠 수 없는 건 왜인지 노트북 마지막에 한 줄 적음 (예: "이 API는 발표일을 안 줘서 공시일을 못 채움")

다 못 해도 한 데까지 올리고, 막힌 곳을 한 줄 적어 주세요.

## 5. GitHub에 올리기

1. Colab 위쪽 메뉴 **파일 → GitHub에 사본 저장**
2. 처음이면 GitHub 로그인·권한 허용 창이 떠요. **허용**을 눌러요. 창이 안 뜨면 브라우저 팝업 차단을 풀어 주세요.
3. "GitHub으로 복사" 창에서 이렇게 채워요.

   | 칸 | 값 |
   |---|---|
   | 저장소 | `내사용자이름/kfa-ai-agent` (기본 선택이 다른 레포일 수 있어요. 꼭 확인) |
   | 브랜치 | `main` |
   | 파일 경로 | `w02_내소스수집.ipynb` (앞에 붙은 `사본`, `Copy of`는 지우기) |
   | 커밋 메시지 | `2회차 과제` |
   | Colab 링크 포함 | 체크 그대로 |

4. **확인**을 누르면 GitHub 페이지가 새 탭으로 열려요. 파일 안에 실행 결과 표까지 보이면 끝이에요.

**자주 생기는 일**

- 저장소 목록에 내 레포가 안 보여요 → 창을 닫고 **F5**(새로고침) 후 다시. 레포를 만든 지 얼마 안 됐으면 자주 생겨요.
- 고치고 다시 올리고 싶어요 → **같은 파일 경로로 다시 저장**하면 새 버전으로 바뀌어요. 이전 버전도 GitHub에 기록으로 남아요.
- CSV도 올려야 하나요? → 필수는 아니에요. 노트북 안에 결과 표가 이미 보여요. 올리고 싶으면 왼쪽 📁에서 CSV를 내려받아, GitHub 레포 화면 **Add file → Upload files**로 올려요.

### 올리기 전 안전 확인

- [ ] 셀 안에 키 값을 직접 적은 곳이 없다 (키는 Secrets로만)
- [ ] 리포트 PDF·기사 원문을 올리지 않는다 (레포가 Public이라 저작권 문제. 원본은 드라이브에만)
- [ ] 다른 사람의 개인정보가 없다

템플릿은 키 값을 화면에 출력하지 않아서, 노트북을 그대로 올려도 키가 공개되지 않아요.

## 6. 막혔을 때

| 보이는 메시지 | 원인 | 해결 |
|---|---|---|
| `DART 키가 없어요` (⏭) | Secrets에 키가 없거나 노트북 액세스가 꺼짐 | 🔑에서 스위치 켜고 **모두 실행** 다시 |
| `DART 010: 등록되지 않은 키예요` | 키를 잘못 복사함 (앞뒤 공백, 일부만 복사) | DART 오픈API 이용현황에서 다시 복사 |
| `DART 013: 조회된 데이터가 없어요` | 그 분기가 아직 공시 전 | `QUARTER`를 하나 앞 분기로 |
| `DART 020: 오늘 요청 한도` | 하루 요청 수를 넘음 | 내일 다시 |
| `...에 연결하지 못했어요` / `인터넷 연결 문제` | 사이트가 잠깐 안 됨 | 1분 뒤 그 셀만 다시 실행 (셀 클릭 → Shift + Enter) |
| `표에 없는 칸: [...]` | `items`에 적은 칸 이름이 실제와 다름 | 메시지 뒤쪽 "지금 표의 칸" 목록에서 정확한 이름 복사 |
| `날짜가 들어 있는 칸 이름을 date_col로` | 날짜 칸을 안 알려줌 | `date_col="날짜 칸 이름"` 추가 |
| `공통 표 모양이 아니에요` | AI가 만든 코드가 `collect_table`을 안 거침 | 마지막 줄이 `return collect_table(...)`인지 확인. `check_records(결과)` 메시지를 AI에게 보여주기 |
| `CSV 글자를 못 읽었어요` | 한글 인코딩 문제 | 엑셀에서 **CSV UTF-8**로 다시 저장 |
| `robots.txt가 코드 수집을 막고 있어요` (⏭) | 사이트가 코드 수집을 허락하지 않음 | 그 자료는 5단계(수동 입력 + 출처카드)로 |
| `페이지에서 '...'가 들어간 표를 못 찾았어요` | 표가 자바스크립트로 그려지는 페이지 | 같은 데이터가 API나 파일로 있는지 먼저 찾기 |
| `예상 못 한 오류 (...)` | 위에 없는 문제 | 셀을 한 번 더 실행. 그래도 안 되면 에러 종류를 조 톡방에 공유 |
