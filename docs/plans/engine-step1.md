## 작업: 에이전트 엔진 1단계: DART 데이터를 공통 레코드 모양으로 가져오기

### 배경
스터디 에이전트 엔진의 첫 조각이야. 앞으로 DART, ECOS, 엑셀, 뉴스 등 어디서 데이터를 가져오든
전부 "같은 모양의 레코드"로 맞춘 뒤에 Gemini 정리 → 코드 검증으로 넘길 거야.
이번 작업은 그 "같은 모양"을 정하고, DART 하나로 모범 예시를 만드는 것까지만이야.
Gemini 호출은 이번 범위에 넣지 마 (다음 단계).

### 0. 키 세팅 (가장 먼저, 이 레포는 Public이라 키 유출 방지가 최우선)
1. .gitignore에 `.env`가 있는지 확인하고 없으면 추가해. data/ 폴더도 같이 추가.
2. `git check-ignore .env` 같은 방법으로 .env가 실제로 무시되는지 확인해서 결과를 보여줘.
3. 레포 맨 위에 `.env` 파일을 만들어. 키 값은 비워두고 아래처럼 자리만 만들어줘.
   키는 내가 VS Code에서 직접 채울 거야. 나한테 키를 대화창에 붙여넣으라고 요청하지 마.
```
   DART_API_KEY=여기에_직접_입력
   GEMINI_API_KEY=여기에_직접_입력
```
4. 키를 읽는 함수 하나를 tools/에 만들어: Colab이면 Secrets(google.colab.userdata), 로컬이면 .env(python-dotenv)에서 읽기.
   키가 없거나 "여기에_직접_입력" 그대로면 쉬운 한국어로 어디에 무엇을 넣으라고 안내하고 멈춰.
   CLAUDE.md에 이미 키 불러오기 규칙이 있으면 그것과 맞춰줘.
5. 키 값을 화면에 출력하거나 로그에 남기지 마. 확인이 필요하면 "앞 4글자 + ****"만.
6. 여기까지 하고 멈춰서 "VS Code에서 .env를 열어 키를 채우세요"라고 알려줘. 내가 채웠다고 하면 다음으로 진행.

### 1. 공통 레코드 모양 (tools/records.py)
레코드 하나 = 숫자 하나 또는 글 하나. 필드:
- record_id: 사람이 읽을 수 있는 고유 id (예: dart_005930_2024_FY_CFS_매출액)
- kind: "number" 또는 "text"
- value: 숫자면 숫자(int/float), 글이면 본문 문자열
- unit: 숫자일 때 단위 (KRW, %, 등). 글이면 None
- as_of: 기준 날짜 "YYYY-MM-DD" (사업연도 데이터면 그 회계연도 말일)
- entity: 대상 (종목코드 또는 회사명)
- item: 항목명 (매출액, 영업이익 등)
- basis: 기준 정보 (예: "연결" / "별도"), 없으면 None
- source: 소스 이름 (DART)
- tier: 수집 단계 1~5 (1=공식 API ... 5=수동)
- source_url: 사람이 원본을 직접 열어볼 수 있는 URL
- collected_at: 수집 시각 (KST, ISO 형식)

필요한 것:
- 레코드를 만들 때 필수 필드 누락·타입 오류·날짜 형식 오류를 잡는 검사 함수
- 레코드 리스트를 JSONL로 저장/불러오기 함수 (저장 위치는 data/ 폴더)
- 레코드 리스트를 pandas DataFrame으로 보여주는 함수

### 2. DART 수집 함수 (tools/collect_dart.py)
- 입력: 종목코드(예: "005930"), 사업연도(예: 2024)
- DART "단일회사 주요계정" API로 매출액·영업이익·당기순이익·자산총계·부채총계·자본총계를 가져와서
  위 레코드 모양으로 변환해 리스트로 반환
- 종목코드 → corp_code 변환은 DART corpCode.xml(zip)을 받아서 처리하고, 매번 받지 않게 data/에 캐시
- 이번엔 사업보고서(연간, reprt_code 11011)만 다뤄

### 꼭 신경 써야 할 부분 (실수가 나기 쉬운 곳)
1. 단위: DART 금액은 "원" 단위이고 쉼표가 들어간 문자열로 와. 숫자로 바꿀 때 쉼표 제거, 음수("-") 처리, 빈 값 처리 확실히.
2. 연결/별도: 같은 항목이 연결(CFS)·별도(OFS) 둘 다 올 수 있어. basis에 반드시 구분해서 넣고 record_id에도 반영.
3. 날짜: as_of는 회계연도 말일. 12월 결산이 아닌 회사가 있을 수 있으니 하드코딩 말고, 확인 어려우면 주석으로 한계 표시.
4. 출처: 응답에 있는 접수번호(rcept_no)로 원본 공시 URL을 만들어서 source_url에 넣어. (사람이 열어서 눈으로 대조할 수 있어야 함)
5. 에러: 키 오류, 데이터 없음(회사/연도 없음), API 호출 한도 초과를 구분해서 쉬운 한국어 메시지로 알려줘.

### 3. 실행 예시 노트북 (notebooks/01_collect_dart.ipynb)
- Colab에서 레포 받아서(git clone) tools/를 불러오는 셀
- Secrets 노트북 액세스를 켜라는 안내 마크다운
- 삼성전자 2024년 수집 → 표로 보여주기 → JSONL 저장 → 다시 불러와서 개수 확인
- 마지막 셀: 매출액 레코드 하나의 source_url을 출력하고, "이 링크를 열어 DART 원본 숫자와 직접 비교해 보세요" 안내
- 각 셀 위에 문과생도 이해할 수 있는 마크다운 설명 한두 줄

### 진행 방식
1. 0번(키 세팅)부터 하고 멈춰서 내가 키를 채울 때까지 기다리기
2. 그다음 1~3번 코드 짜기 전에 파일 구조와 함수 목록을 먼저 계획으로 보여주고 내 확인 받기
3. 확인 후 작성, 로컬에서 실행해서 삼성전자 2024년 결과 직접 보여주기
4. 이 함수가 "다른 소스 함수의 모범 예시"가 될 거라서, collect_dart.py 맨 위에
   "새 소스 함수를 만들 때 지켜야 할 규칙" 주석(반환 모양, 단위·날짜·출처 처리)을 짧게 정리해줘
5. 커밋 전에 반드시 `git status`로 올라갈 파일 목록을 보여주고, .env나 data/가 목록에 없는지 확인한 결과를 같이 말해줘. 내 확인 받고 커밋.
